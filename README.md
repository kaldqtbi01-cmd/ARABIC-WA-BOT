# ARABIC-WA-BOT

بوت واتساب عربي قابل للتوسع يعمل على Termux باستخدام Node.js وBaileys. يعيد تنفيذ الميزات المطلوبة من الصفر؛ لا ينسخ ملفات Toxic-MD-Arabic. هذا المشروع لا يستخدم WhatsApp API رسميًا؛ Baileys مشروع غير رسمي، لذلك راجع شروط المنصة ومخاطر الحساب قبل ربط رقمك.

## الموجود حاليًا

- ربط WhatsApp برمز رقمي أو QR، حفظ الجلسة محليًا، وإعادة الاتصال بعد الانقطاع.
- استقبال كل عناصر دفعة الرسائل، توجيه الأوامر بالبادئة، تحميل ملفات الإضافات من مجلد المشروع، وكشف تكرار الرسائل.
- أوامر عربية أساسية: `.مساعدة`، `.فحص`، `.المدة`، `.حاسبة`، `.ترميز`، `.فك_ترميز`، `.معلومات_المجموعة`، `.خدمات`.
- أدوات بحث خارجية: `.ويكيبيديا`، `.طقس`، `.حزمة`، `.مستودع`.
- إدارة مجموعات بصلاحيات: `.طرد` و`.ترقية` و`.تنزيل` لعضو واحد، `.تحذير` و`.التحذيرات`، `.روابط تشغيل|إيقاف`، `.سبام تشغيل|إيقاف`، `.ترحيب تشغيل|إيقاف`، `.رسالة_الترحيب`، `.رسالة_الوداع`، `.منشنالمشرفين`، `.منشنالكل` بحدود، `.قفل`، `.فتح`، `.رابط_المجموعة`.
- وسائط محلية عبر FFmpeg: `.ملصق` من صورة أو فيديو قصير، `.صوت` لاستخراج الصوت من فيديو، و`.متحركة` لتحويل فيديو إلى GIF.
- ألعاب محلية: `.عملة`، `.نرد`، `.خمن`، `.لغز`، `.جواب`.
- نقاط محلية مخزنة: `.رصيدي`، `.يومي`، `.تحويل @عضو مبلغ`، `.المتجر`، `.شراء اسم`، `.الترتيب`.
- أوامر مالك محدودة: `.وضع_خاص`، `.وضع_عام`، `.إحصائيات`.
- `.ذكاء` جاهز عبر واجهة متوافقة مع OpenAI إذا وفّرت إعدادات المزود محليًا.
- تخزين JSON محلي بكتابة ذرية وإعدادات منفصلة لكل مجموعة.

## غير مفعّل بعد

تنزيلات المنصات، إنشاء الصور، تحليل الصور، OCR، الترجمة، TTS/STT، ألعاب الشطرنج وXO، والتخزين متعدد الأجهزة. بعضها يحتاج اعتماديات محلية وبعضها يحتاج مزود API موثوقًا لم يُختر أو يُختبر بعد. قائمة الخدمات ومفاتيحها المحتملة في [docs/SERVICES.md](docs/SERVICES.md).

## متطلبات Termux

- Termux من مصدره الرسمي.
- Node.js 20 أو أحدث وnpm.
- FFmpeg لأوامر الملصق والصوت وGIF.
- إنترنت وحساب WhatsApp للاختبار.

```sh
pkg update -y
pkg install nodejs-lts ffmpeg unzip -y
unzip /sdcard/Download/ARABIC-WA-BOT.zip -d "$HOME/ARABIC-WA-BOT"
cd "$HOME/ARABIC-WA-BOT"
if [ ! -f .env ]; then cp .env.example .env; fi
nano .env
node --version
npm install
npm test
npm start
```

في `.env`، اضبط `PAIRING_NUMBER` برقم WhatsApp بصيغة دولية وأرقام فقط إذا رغبت برمز رقمي، واضبط `OWNER_NUMBERS` لرقم المالك بالطريقة نفسها. لا ترسل هذه القيم أو ملف البيئة في المحادثة. لا تستبدل `.env` إذا كان موجودًا وفيه إعداداتك؛ أضف إليه فقط المتغيرات الجديدة التي تحتاجها. عند التشغيل الأول، امسح QR أو أدخل رمز الربط من قائمة الأجهزة المرتبطة في WhatsApp. نجاح الاتصال يظهر في Termux.

لإعداد الذكاء الاصطناعي، عيّن `AI_BASE_URL` و`AI_API_KEY` و`AI_MODEL` من حساب مزود متوافق. لا تضع المفاتيح في ملف الشيفرة. الأمر `.ذكاء` يرسل النص للمزود الذي تضبطه؛ لا تستخدمه لإرسال معلومات حساسة.

## تخزين وأمان

جلسات WhatsApp في `sessions/auth` وملف `.env` وبيانات المستخدمين في `database/data.json` محلية ولا ينبغي مشاركتها أو رفعها. لا يمسح البرنامج الجلسة عند الإيقاف. الإعدادات الاقتصادية والمجموعات تُحفظ على جهاز التشغيل؛ انسخ `database/data.json` يدويًا إذا أردت نسخة احتياطية.

لا يحتوي المشروع على `eval` أو تنفيذ shell من الرسائل أو تحميل إضافات من الإنترنت. حُدّ تنفيذ المجموعة على عضو واحد في كل مرة، وفُرضت صلاحيات المشرف، وقُيد المنشن الجماعي. لا توجد ميزة بث جماعي أو حذف/ترقية جماعية.

## نتائج الاختبار وحدوده

يجري اختبار محلي لأسماء الأوامر وصحة المحمّل والتخزين وبعض وظائف المنطق، ويتضمن تحويل صورة اختبارية إلى WebP عند توفر FFmpeg. نجاح `npm test` لا يثبت تسجيل الدخول إلى WhatsApp أو توافر API خارجي. لم يكتمل اتصال فعلي على هاتف المستخدم ولم تُختبر الخدمات الخارجية. لا تعتبر أي وظيفة خارجية مكتملة حتى تختبر على Termux وتظهر نتيجتها.
