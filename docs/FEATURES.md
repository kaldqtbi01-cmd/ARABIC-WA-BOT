# حالة الميزات الحالية

## منفذة في الشيفرة

- الاتصال بواتساب عبر Baileys غير الرسمي، pairing code أو QR، حفظ الجلسة واستعادتها بعد الانقطاع.
- استقبال دفعات الرسائل وتوجيه الأوامر العربية وتحميل الإضافات المحلية وكشف تكرار معرف الرسالة.
- أوامر عامة وحاسبة رياضية بمحلل محدود بدل تنفيذ JavaScript.
- إدارة مجموعات بصلاحيات موحدة: إجراء على عضو واحد، قفل/فتح، رابط المجموعة، تحذيرات يدوية بلا طرد آلي، الترحيب/المغادرة، الحماية من الروابط والتكرار، والمنشن الجماعي المقيد.
- أدوات HTTP ثابتة الوجهة للطقس وWikipedia وسجل npm ومعلومات مستودع GitHub العام.
- ألعاب محلية للنرد والعملة والتخمين والألغاز.
- رصيد وتحويل ومكافأة يومية ومتجر افتراضي وترتيب مع تحديثات JSON متسلسلة وكتابة ذرية داخل عملية واحدة.
- ملصقات من صور أو فيديو قصير، استخراج صوت حتى 60 ثانية، وتحويل GIF حتى 8 ثوانٍ بواسطة FFmpeg محلي؛ حجم الوسيط 8 MiB كحد أقصى ومدة التحويل محدودة.
- أمر ذكاء اختياري عبر Chat Completions متوافق، عند ضبط `AI_BASE_URL` و`AI_API_KEY` و`AI_MODEL` في `.env`.
- أوامر مالك محدودة تعتمد على `OWNER_NUMBERS`، دون eval أو shell أو بث جماعي.

## غير منفذة أو تحتاج اختيار اعتماد

- تنزيلات المنصات وSpotify وMediaFire.
- إنشاء الصور وتحليلها وOCR وإزالة الخلفية وتحسين الجودة.
- ترجمة API مستقرة وTTS/STT.
- لعبة الشطرنج وXO ومباريات متعددة اللاعبين.
- تصويت، قبول/رفض طلبات الانضمام، إدارة صلاحيات أكثر تفصيلًا، أو طرد/ترقية جماعية.
- قاعدة بيانات خادمية أو لوحة ويب.

هذه الوظائف تحتاج خدمات وواجهات موثقة أو اعتماديات محلية لم يتم اختيارها/تثبيتها/اختبارها بعد. تُراجع `SERVICES.md` لمعرفة ما قد تحتاجه كل فئة. نجاح الاختبارات المحلية لا يثبت نجاح هذه الوظائف ولا اتصال واتساب الفعلي.
