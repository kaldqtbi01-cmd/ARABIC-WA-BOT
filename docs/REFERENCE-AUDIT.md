# مراجعة المستودع المرجعي

المستودع الذي طلب المستخدم مراجعته: https://github.com/kaldqtbi01-cmd/Toxic-MD-Arabic

نُسخ المشروع إلى مساحة منفصلة بغرض القراءة فقط. فُحصت النواة والاتصال والإضافات والذكاء الاصطناعي والتنزيلات والوسائط وإدارة المجموعات والحماية والألعاب والاقتصاد والأدوات وأوامر المالك والاعتماديات. لم تُشغّل شيفرة المرجع ولم تُثبّت اعتمادياته. الخلاصة المفصلة المرفقة للمستخدم في ملف `REFERENCE-AUDIT-FULL.md` عند توفره.

شوهدت أفكار قابلة لإعادة البناء، منها معالج رسائل متعدد الإضافات وأوامر عربية، أدوات مجموعات، ألعاب محلية، دردشة ذكاء اصطناعي، وتحويلات وسائط. لم يُعثر على تنفيذ نظام اقتصاد متكامل ضمن الملفات المراجعة. أظهر الجرد متغيرات ومفاتيح مرتبطة بخدمات مثل Groq وGitHub وGoogle Custom Search وOCR.space وPostgreSQL وHeroku، إضافة إلى endpoints تنزيل/وسائط غير موثقة؛ هذا ليس إثباتًا على عمل الخدمات أو كونها مجانية.

وجد التدقيق مخاطر تنفيذ `eval` وshell وإضافات غير معزولة، وأسرارًا مضمّنة أو مُعتّمة، وفحوص صلاحيات غير متسقة، وعمليات جماعية عالية الأثر، وواجهات غير رسمية، وتعديل ملفات داخل `node_modules`، وتعطيل تحقق TLS في مسار قاعدة البيانات. لم يظهر ملف ترخيص في جرد ملفات الجذر؛ لذلك لم يُنسخ أي كود من المرجع. نُفذت وظائف البوت الحالية من الصفر مع حدود وصلاحيات؛ مراجعة الوضع الراهن في `FEATURES.md`، وخدمات API ومفاتيحها المحتملة في `SERVICES.md`.
