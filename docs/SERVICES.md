# الخدمات الخارجية المطلوبة أو الاختيارية

هذا الجرد مبني على الملفات التي ظهرت في مراجعة المستودع المرجعي وعلى الكود المفعّل في ARABIC-WA-BOT. لم تُختبر الأسعار أو صلاحية المفاتيح أو شروط المزودين؛ وجود اسم خدمة لا يعني أنها متاحة أو مجانية أو موصى بها.

## ما يعمل دون API key

الأوامر الأساسية والحاسبة والألعاب والنقاط وإعدادات المجموعات وتخزين JSON تعمل محليًا. الوسائط المحلية `.ملصق` و`.صوت` و`.متحركة` تستخدم FFmpeg المثبت على الجهاز، ولا تحتاج خدمة رفع. أدوات `.ويكيبيديا` و`.طقس` و`.حزمة` و`.مستودع` تستخدم HTTP إلى خدمات عامة وتحتاج إنترنت، وقد تخضع لحدود أو تغييرات من المزود.

## الذكاء الاصطناعي — مفتاح من حسابك

الأمر `.ذكاء` يتكامل مع واجهة متوافقة مع OpenAI Chat Completions. ضع إعدادات مزودك في `.env` المحلي فقط:

```env
AI_BASE_URL=https://عنوان-المزود/v1
AI_API_KEY=مفتاح_من_حسابك
AI_MODEL=اسم-النموذج
```

مثال Groq (عنوان مزود فقط، لا يتضمن مفتاحًا أو ضمانًا لخطة مجانية): `AI_BASE_URL=https://api.groq.com/openai/v1`، و`AI_API_KEY` هو مفتاحك الصادر من حسابك، و`AI_MODEL` اسم نموذج متاح في حسابك. ما زالت حدود الخدمة وأسعارها الحالية تحتاج تحققًا من المزود. أرسل نصًا عاديًا فقط؛ النص يذهب إلى المزود.

## الخدمات التي لم تُفعّل

الفحص المرجعي أظهر استخدام Groq للدردشة/الصوت، GitHub REST، Google Custom Search، OCR.space، OMDb، ومزودي تنزيل أو وسائط مثل واجهات Ryuu وEllyTube وApiziaul وSidy وNexRay وGifted وPollinations، إضافة إلى خدمات رفع/تحويل طرف ثالث. من المحتمل أن تتطلب هذه الخدمات مفتاحًا أو معرّف محرك أو اعتمادًا خاصًا؛ لم تُثبت صلاحيتها أو توافرها أو تسعيرها أو شروطها. لم ننفذ تلك الموصلات بعد ولم ننسخ مفاتيحها من المصدر.

لمعرفة احتياجات عند اختيار ميزة محددة:

- OCR: ستحتاج مزود OCR موثقًا ومفتاحه؛ ظهرت OCR.space في المصدر.
- بحث Google: يحتاج عادةً بيانات اعتماد Google Custom Search ومعرّف محرك بحث؛ لم يُنفذ الأمر.
- تحليل صور/توليد صور/إزالة خلفية/STT/TTS/ترجمة: يلزم اختيار مزود موثق وتحديد عنوانه وصيغة الطلب ومفتاحه/خطته قبل برمجته واختباره.
- تنزيل المنصات وSpotify/MediaFire: يحتاج API معروفًا وقانونيًا/مسموحًا وشروطًا واضحة؛ لا تعتمد على endpoints عامة غير موثقة قبل التحقق منها.
- وكيل GitHub للكتابة أو إنشاء مستودعات يحتاج GitHub token بصلاحيات محدودة وموافقة مستقلة؛ هذه القدرة غير موجودة في بوتنا.
- `DATABASE_URL` اختياري لخادم PostgreSQL إذا قررت التخزين الخارجي؛ ليس مطلوبًا لتشغيل Termux حاليًا.
- `HEROKU_API_KEY` و`HEROKU_APP_NAME` لإدارة تطبيق Heroku فقط، ولا يحتاجهما هذا المشروع على Termux.

**لم أستخرج أو أنقل أي قيمة سرية من المستودع.** فحص المصدر رصد مفاتيح أو ثوابت اعتماد ظاهرة/مضمّنة؛ اعتبر المفاتيح التي وُضعت علنًا معرضة، ودوّرها لدى أصحاب الخدمات. لا ترسل أي مفتاح أو كلمة مرور أو جلسة هنا. أضف الأسرار بنفسك إلى `.env` المحلي، وهو مستبعد من الأرشيف وGit.
